\# Statistics Practical Project



This project demonstrates practical applications of statistics using Python, Jupyter Notebook, NumPy, Pandas, Matplotlib, Seaborn, and SciPy.

Setup



Create and activate the Python virtual environment:



python -m venv .venv

.\\.venv\\Scripts\\Activate.ps1



Install the required dependencies:



python -m pip install -r requirements.txt

Running the Notebook



Start Jupyter Notebook:



python -m notebook



Open:



notebooks/statistics\_practice.ipynb



Select the Python environment:



Python (Statistics Practical)



Run the notebook cells from top to bottom.



Output



The project generates statistical calculations, visualizations, and insights.
